# 🏠 EstateEase AI – Real Estate Chatbot

EstateEase AI is an AI-powered real estate chatbot that helps users quickly find properties based on their requirements such as location, BHK, budget, and property type.

It provides a conversational way to search and explore property listings, making the real estate discovery process faster and easier.

## Key Features

- 🔎 Natural-language property search
- 🏠 Property recommendations
- 📍 Location-based filtering
- 💰 Budget-based property search
- 💬 Interactive AI chatbot
- 🌐 Embeddable chat widget
- 📱 Responsive user interface

## Tech Stack

Python, Flask, HTML, CSS, JavaScript, AI/LLM, Database Integration
